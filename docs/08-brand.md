# SplitBed 品牌個性與視覺系統

2026-08-29。改任何介面之前先讀呢份。實作喺 `src/ui/shared.css`。

## 1. 一句話個性

> **SplitBed 係一部儀表板，唔係一份文件。**

飛機駕駛艙、任務控制室、專業器材 —— 冷靜、精準、密度高、數字先行。
唔係教科書，唔係說明書，唔係企業簡報。

## 2. 三條可以判斷對錯嘅規則

| 規則 | 意思 | 判斷方法 |
|---|---|---|
| **一屏一個焦點** | 每一屏只有一樣嘢最大最亮 | 瞇埋眼睇，應該只剩一樣嘢跳出嚟。跳出兩樣就係錯 |
| **字細、行緊、格密** | 專業工具唔會大字疏行 | 內文超過 1rem、行距超過 1.7 就係太鬆 |
| **解釋收埋做浮標** | 平時只見標題同數字 | 一段多過兩行嘅解釋，應該變做 `?` 浮標 |

第三條係最容易犯嘅。冗長說明堆喺畫面上會令人**乜都睇唔到**，
因為所有嘢都一樣大聲。收埋之後，重點自然浮出嚟。

## 3. 語氣

- **講事實，唔講形容詞。**「一季多賺 ¥253,700」，唔係「大幅提升營運效率」
- **講得出限制。** 做唔到嘅嘢照寫，唔包裝成「即將推出」
- **唔用術語。** 唔會出現 constraint、optimizer、演算法、目標函數
- **廣東話口語，唔硬譯。** 寫俾旅舍老闆睇，唔係寫俾投資人睇

## 4. 色票

深色為主。淺色係備選，唔係預設。

### 深色（主）

| 用途 | 色值 | 理由 |
|---|---|---|
| 背景 | `#060911` | 接近黑但帶藍，深空 |
| 卡面 | `#0d1222` | 同背景分得開但唔跳 |
| 卡面（第二層） | `#131a2e` | 浮標、內嵌區塊 |
| 邊框 | `#1f2740` | 平時幾乎睇唔到 |
| 邊框（強） | `#33405f` | hover、要分隔嗰陣 |
| 文字 | `#e9edfa` | 唔用純白，減少刺眼 |
| 次要文字 | `#8c96b4` | 大部分說明文字用呢個 |
| **主色** | `#7d97ff` | 電光藍紫。**只用喺重點同互動** |
| 主色底 | `rgba(125,151,255,.13)` | hover 背景、浮標圈 |
| 第二色 | `#b98cff` | 星雲紫。只用喺漸層，唔做單獨元素 |
| 正向 | `#3ad9a4` | 極光綠。多賺、改善 |
| 警告 | `#ffc46b` | 琥珀。限制、注意 |

### 淺色（備）

背景 `#edf0f8`／卡面 `#ffffff`／文字 `#0d1426`／次要 `#5b6580`／
主色 `#3a56d8`／第二色 `#7a45d4`／正向 `#0b8f68`／警告 `#b26a00`

### 星雲背景

兩個大半徑 radial-gradient 疊喺背景色上，左上藍、右上紫，透明度極低（0.14／0.10）。
`background-attachment: fixed`，捲動時唔會郁 —— 有深度但唔搶戲。

## 5. 字級

基準 **15px**（`html { font-size: 15px }`）。所有 rem 一次過收窄 6%。

| 用途 | 大小 | 行距 |
|---|---|---|
| 內文 | `1rem` | 1.55 |
| 次要說明 | `0.88–0.92rem` | 1.6 |
| 浮標內容 | `0.82rem` | 1.5 |
| 小標題 h3 | `0.97–1rem` | 1.35 |
| 區段標題 h2 | `clamp(1.1rem, 2vw, 1.55rem)` | 1.3 |
| 頁面主標 h1 | `clamp(1.6rem, 3.4vw, 2.5rem)` | 1.2 |
| **焦點數字** | `clamp(2.1rem, 4.4vw, 2.9rem)` | 1.05 |

標題一律 `letter-spacing: -0.02em`。
**所有數字用 `font-variant-numeric: tabular-nums`**，欄位先對得齊。

## 6. 互動：乜都要有 hover

冇 hover 嘅介面感覺似截圖。

| 元素 | hover |
|---|---|
| 卡片 | 邊框轉主色 + 上移 2–3px + 光暈 |
| 表格行 | 背景轉主色底 |
| 導覽連結 | 文字轉亮 + 主色底背景 |
| 主要按鈕 | 光暈 |
| 次要按鈕 | 邊框轉主色 |
| 浮標圈 | 轉主色 + 3px 光環 |
| 連結 | 底線加粗（唔係轉色） |

過場一律 `0.14–0.16s ease`。`prefers-reduced-motion` 全部關掉。

## 7. 浮標（`.info-dot`）

冗長解釋唔應該擺喺畫面上。用法：

```html
<span class="info-dot" tabindex="0" role="button" aria-describedby="tip-x">?
  <span id="tip-x" role="tooltip">解釋內容</span>
</span>
```

- 平時只見一個 1rem 嘅圈
- hover 或鍵盤聚焦先顯示，上方置中，最闊 20rem
- 貼住左邊嘅加 `.align-start`，避免標出畫面外
- **手機用 tap 都出得到**（`:focus-within`）

## 8. 用色紀律

主色 `#7d97ff` **只用喺三個地方**：焦點數字、互動狀態、區段 kicker。
其餘一律灰階。

一見到主色出現喺三個以上唔相干嘅地方，即係用濫咗 —— 咁樣就冇嘢係重點。

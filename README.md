# SplitBed

Smart Room & Bed Allocation — 給 Hostel / Guesthouse / 員工宿舍 / 滑雪宿舍的
房間與床位自動分配系統。

住宿方自行設定規則（Same-gender / Mixed / Hybrid / Female-only / Private / Staff），
系統根據訂單、日期、房間、床位與規則，計算最少 inventory waste 的安排建議。
建議交員工確認，系統不會自行改房。

規格見 `docs/`。開發從 Phase 0（引擎 + 模擬器，無 DB 無 UI）開始，見 `docs/03-roadmap.md`。
